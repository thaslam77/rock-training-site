# ROCK — static site

Plain HTML, CSS, and JavaScript. No build step.

## GitHub Pages

1. Create a new repo
2. Upload everything in this folder to the **repo root** (`index.html` at the top)
3. Settings → Pages → Deploy from a branch → `main` / root
4. Share `https://YOUR-USERNAME.github.io/REPO-NAME/`

## Pages

| File | Page |
|---|---|
| `index.html` | Home |
| `training.html` | Training |
| `programs.html` | Remote waitlist + sample week |
| `results.html` | Results |
| `about.html` | About Rock |
| `book.html` | Consult form |

Forms open the visitor’s email app. Edit `train@rockmassey.co` in `js/site.js` when you have a real address.
